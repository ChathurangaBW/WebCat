# WebCat Brand Guidelines

## Product Name

**WebCat** — AI-assisted web-application penetration-testing platform

- CLI command: `webcat`
- User configuration: `~/.webcat`
- Project configuration: `.webcat`
- Environment variable prefix: `WEBCAT_`
- Package scope: `@webcat/*`

## Logo

The WebCat logo combines a cat-head silhouette with a shield motif, representing the platform's dual nature: intelligent exploration (cat) and security protection (shield).

### Components
- **Shield** — Security, protection, authorized testing boundary
- **Cat head** — Intelligence, curiosity, thorough exploration
- **Eyes and whiskers** — Perception, passive discovery, attention to detail
- **Terminal cursor** — Technical tooling, developer-first approach

- `apps/webcat-web/public/favicon.svg` — 32×32 favicon

## Typography

- Primary: Inter (variable weight)
- Monospace: JetBrains Mono (for code, traffic, technical data)

## Voice

- Professional, precise, security-focused
- Technical but accessible to security practitioners
- Never implies automated hacking or autonomous exploitation
- Always emphasizes authorized, scoped testing
